# Sohini Banerjee — Portfolio & Career Kit

A complete start-kit for your transition into management (project management, marketing, HR) and teaching.

## Files

| File | Purpose |
|---|---|
| `index.html` + `css/style.css` | Your personal website (simple HTML/CSS) |
| `linkedin-profile.md` | Copy-paste guide to build your LinkedIn profile |
| `career-roadmap.md` | Your 6–12 month plan into management & teaching |
| `resume/SohiniBanerjee-Resume.pdf` | Your one-page resume (downloadable from the site) |
| `build_resume.py` | Generates the resume PDF (`python3 build_resume.py`) |
| `CERTIFICATES/` | Your Google PM certificate PDFs (linked on the site) |

## Edit the resume

The resume is generated by `build_resume.py` (pure Python, no dependencies):

```bash
python3 build_resume.py   # rebuilds resume/SohiniBanerjee-Resume.pdf
```

Edit the text in the `build()` function to update your details, then re-run.

## Personalize before publishing (search for these)

- `https://www.linkedin.com/in/your-handle` in `index.html` → your LinkedIn URL
- College name, volunteer roles, and exact dates in `linkedin-profile.md`
- Your city/location under the Open-To-Work settings

## Preview the site locally

Open `index.html` directly in a browser (double-click), or:

```bash
# Python 3
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publish free with GitHub Pages

1. Create a repo at https://github.com/new named `sohini-banerjee` (public).
2. Upload the `index.html` and `css/` folders to it.
3. Repo → **Settings** → **Pages** → Source: `Deploy from a branch` → `main` / root → Save.
4. Your site is live at `https://your-username.github.io/sohini-banerjee/` in ~2 minutes.
5. Use your new site URL in your LinkedIn "Featured" section.

> Alternative free hosts: Netlify Drop (drag-and-drop) or Cloudflare Pages.
